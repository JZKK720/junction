# Junction

一个将编辑器连接到本地 AI 编程智能体的 VS Code 聊天侧边栏。

`7 个后端` · `聊天侧边栏` · `工作区上下文` · `动画启动屏` · `MIT 许可证`

![两种熟悉的主题](../media/two_familiar_skins.png)

Junction 是一个 VS Code 聊天面板，可连接到运行在本地的 AI 编程智能体。
它通过统一的界面与多个智能体后端通信——无需切换工作流即可在不同后端之间自由切换。

## 支持的后端

Junction 可连接以下本地智能体运行时：

- **OpenClaw** — WebSocket 网关集成，支持会话和模型管理
- **Hermes** — 原生仪表盘 WebSocket 和 REST API 支持
- **Souveraine** — HTTP 服务器集成，支持托管运行时启动
- **MiMoCode** — 自动启动或预配置的 MiMo 服务器连接
- **Goose** — 数据目录和密钥配置
- **OpenCode** — 二进制路径和配置目录设置
- **OpenHands** — 服务器启动器和主目录配置

## 功能特性

### 聊天侧边栏
从 VS Code 的辅助侧边栏与当前活跃的智能体对话。通过命令面板打开：`Junction: Open Sidebar`。

### 工作区上下文
将文件拖放到聊天输入框，或右键点击文件/选区将其添加到当前对话线程。

### 模型与推理选择器
在侧边栏标题栏中选择模型，并为每个会话设置推理强度。

### Markdown 渲染
智能体回复、工具调用卡片、推理块和差异对比均以内联方式渲染，支持语法高亮。

### 聊天布局
在紧凑模式（活动折叠到手风琴面板中）和时间线模式（按时间顺序排列的推理流，用户消息置顶）之间切换。

### 跟进模式
在智能体处理完成后排队发送消息、中途引导，或中断并重新定向。支持全局或按桥接器单独配置。

### 自动重连
连接断开时 Junction 会自动重连到运行时，无需手动重启。

## 主题

Junction 内置两种布局。**紧凑模式**将活动折叠到摘要手风琴面板中，呈现密集视图。
**时间线模式**展示带圆点指示器的按时间排序的活动轨道，可展开推理内容，并采用橙色强调主题。
两种布局均会适配你的 VS Code 颜色主题。

## 启动屏与动画

Junction 打开时会显示一个动画启动屏，品牌标识后方呈现矩阵风格的雨滴特效。
启动屏可通过编辑器内的动画面板进行完全自定义。

### 字符集
雨滴特效支持 10 种字符集：片假名、Matrix 拉丁、拉丁、平假名、CJK、韩文、Emoji、二进制、符号和自定义。
可按配置的概率混入 emoji 雨滴，或提供自定义字符集。

### 雨滴控制
- **方向** — 切换雨滴向上或向下飘落
- **反向概率** — 设置雨滴反向飘落的百分比
- **边缘弹射** — 雨滴从左右边缘弹回，而非飘出屏幕
- **重力、弹射、碰撞、速度** — 调整雨滴的运动方式及与品牌标识的交互
- **数量、大小变化、颜色变化、透明度范围** — 控制雨滴的密度和外观
- **自定义颜色** — 为雨滴和品牌标识选择颜色及透明度
- **Emoji 混合** — 开启后设置稀有度为 1/N（1 = 全部 emoji，1000000 = 百万分之一）

### 退出动画
启动屏消失时，品牌标识会通过以下 9 种动画模式之一退出。
每种模式都有自己的控制滑块，在下拉菜单中选择后自动切换显示。

- **向外螺旋** — 字母从中心向外螺旋散开
- **向内螺旋** — 字母聚拢为逐渐收紧的螺旋，可配置半径和长度
- **爆炸** — 字母在重力作用下向外爆散
- **爆炸 2** — 基于物理的爆炸效果，带边缘弹射，可配置力度、混乱度和各轴动量
- **漂浮远去** — 字母沿方向倾斜向上漂移
- **水平压扁** — 字母水平展开并压成 1px 线条，可配置保持时间
- **弱爆炸** — 力度更小的柔和爆炸
- **星球大战字幕** — 字母汇聚到消失点，可配置目标 Y 坐标
- **爆炸 3** — 品牌标识碎裂成单个像素，可按轴控制动量
- **雨滴推挤** — 字母脱离后被雨滴物理推离屏幕
- **随机** — 每次随机选择不同模式

### 动画面板
点击聊天标题栏的齿轮图标打开动画面板。包含三个标签页：聊天、浮标和启动屏。
启动屏标签页包含两个可折叠面板（外观和运动）、带各模式滑块的退出模式下拉菜单，以及一个可点击测试动画的实时预览画布。
面板可自由拖拽和调整大小，无高度限制。

## 安装

### 从源码安装
```bash
npm install
./compile-and-install.sh
# 然后：Ctrl+Shift+P → Developer: Reload Window
```

### 系统要求
- VS Code 1.120.0 或更高版本
- 运行中的本地智能体运行时（如 OpenClaw Gateway、Hermes 仪表盘、Souveraine 服务器）
