# Junction

一個將編輯器連接到本地 AI 程式設計代理程式的 VS Code 聊天側邊欄。

`7 個後端` · `聊天側邊欄` · `工作區上下文` · `動畫啟動畫面` · `MIT 授權條款`

![兩種熟悉的佈景主題](../media/two_familiar_skins.png)

Junction 是一個 VS Code 聊天面板，可連接到運行在本地的 AI 程式設計代理程式。
它透過統一的介面與多個代理程式後端通訊——無需切換工作流程即可在不同後端之間自由切換。

## 支援的後端

Junction 可連接以下本機代理程式執行環境：

- **OpenClaw** — WebSocket 閘道整合，支援工作階段與模型管理
- **Hermes** — 原生儀表板 WebSocket 與 REST API 支援
- **Souveraine** — HTTP 伺服器整合，支援託管執行環境啟動
- **MiMoCode** — 自動啟動或預先設定的 MiMo 伺服器連線
- **Goose** — 資料目錄與金鑰設定
- **OpenCode** — 執行檔路徑與設定目錄設定
- **OpenHands** — 伺服器啟動器與主目錄設定

## 功能特色

### 聊天側邊欄
從 VS Code 的輔助側邊欄與當前作用中的代理程式對話。透過命令選擇區開啟：`Junction: Open Sidebar`。

### 工作區上下文
將檔案拖放到聊天輸入框，或按右鍵點擊檔案/選取範圍將其加入目前的討論串。

### 模型與推理選擇器
在側邊欄標題列中選擇模型，並為每個工作階段設定推理強度。

### Markdown 渲染
代理程式回覆、工具呼叫卡片、推理區塊與差異比對均以內嵌方式呈現，支援語法突顯。

### 聊天版面配置
在精簡模式（活動摺疊至手風琴面板中）與時間軸模式（按時間順序排列的推理流程，使用者訊息固定於頂端）之間切換。

### 後續訊息模式
在代理程式處理完成後佇列傳送訊息、中途引導，或中斷並重新導向。支援全域或依橋接器個別設定。

### 自動重新連線
連線中斷時 Junction 會自動重新連線到執行環境，無需手動重新啟動。

## 佈景主題

Junction 內建兩種版面配置。**精簡模式**將活動摺疊到摘要手風琴面板中，呈現緊湊的檢視。
**時間軸模式**展示帶圓點指示器的按時間排序的活動軌道，可展開推理內容，並採用橘色強調佈景主題。
兩種版面配置均會適配你的 VS Code 顏色佈景主題。

## 啟動畫面與動畫

Junction 開啟時會顯示動畫啟動畫面，品牌標誌後方呈現矩陣風格的雨滴特效。
啟動畫面可透過編輯器內的動畫設定面板進行完全自訂。

### 字元集
雨滴特效支援 10 種字元集：片假名、Matrix 拉丁、拉丁、平假名、CJK、韓文、Emoji、二進位、符號和自訂。
可依設定的機率混入 emoji 雨滴，或提供自訂字元集。

### 雨滴控制
- **方向** — 切換雨滴向上或向下飄落
- **反向機率** — 設定雨滴反向飄落的百分比
- **邊緣彈射** — 雨滴從左右邊緣彈回，而非飄出螢幕
- **重力、彈射、碰撞、速度** — 調整雨滴的運動方式及與品牌標誌的互動
- **數量、大小變化、顏色變化、透明度範圍** — 控制雨滴的密度和外觀
- **自訂顏色** — 為雨滴和品牌標誌選擇顏色及透明度
- **Emoji 混合** — 開啟後設定稀有度為 1/N（1 = 全部 emoji，1000000 = 百萬分之一）

### 退出動畫
啟動畫面消失時，品牌標誌會透過以下 9 種動畫模式之一退出。
每種模式都有自己的控制滑桿，在下拉選單中選擇後自動切換顯示。

- **向外螺旋** — 字母從中心向外螺旋散開
- **向內螺旋** — 字母聚攏為逐漸收緊的螺旋，可設定半徑和長度
- **爆炸** — 字母在重力作用下向外爆散
- **爆炸 2** — 基於物理的爆炸效果，帶邊緣彈射，可設定力度、混亂度和各軸動量
- **漂浮遠去** — 字母沿方向傾斜向上漂移
- **水平壓扁** — 字母水平展開並壓成 1px 線條，可設定保持時間
- **弱爆炸** — 力度較小的柔和爆炸
- **星際大戰字幕** — 字母匯聚到消失點，可設定目標 Y 座標
- **爆炸 3** — 品牌標誌碎裂成單個像素，可依軸控制動量
- **雨滴推擠** — 字母脫離後被雨滴物理推離螢幕
- **隨機** — 每次隨機選擇不同模式

### 動畫設定面板
點擊聊天標題列的齒輪圖示開啟動畫設定。包含三個分頁：聊天、浮標和啟動畫面。
啟動畫面分頁包含兩個可摺疊面板（外觀和動作）、帶各模式滑桿的退出模式下拉選單，以及一個可點擊測試動畫的即時預覽畫布。
面板可自由拖曳和調整大小，無高度限制。

## 安裝

### 從原始碼安裝
```bash
npm install
./compile-and-install.sh
# 然後：Ctrl+Shift+P → Developer: Reload Window
```

### 系統需求
- VS Code 1.120.0 或更高版本
- 運行中的本機代理程式執行環境（如 OpenClaw Gateway、Hermes 儀表板、Souveraine 伺服器）
