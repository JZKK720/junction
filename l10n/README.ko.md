# Junction

에디터를 로컬 AI 코딩 에이전트에 연결하는 VS Code 채팅 사이드바.

`7개 백엔드` · `채팅 사이드바` · `워크스페이스 컨텍스트` · `애니메이션 스플래시` · `MIT 라이선스`

![두 가지 익숙한 테마](../media/two_familiar_skins.png)

Junction은 로컬에서 실행되는 AI 코딩 에이전트에 연결하는 VS Code 채팅 패널입니다.
통합된 인터페이스를 통해 여러 에이전트 백엔드와 통신 — 워크플로를 변경하지 않고 전환할 수 있습니다.

## 지원 백엔드

Junction은 다음 로컬 에이전트 런타임에 연결할 수 있습니다:

- **OpenClaw** — 세션 및 모델 관리를 갖춘 WebSocket 게이트웨이 통합
- **Hermes** — 네이티브 대시보드 WebSocket 및 REST API 지원
- **Souveraine** — 관리형 런타임 스포닝을 갖춘 HTTP 서버 통합
- **MiMoCode** — 자동 시작 또는 사전 구성된 MiMo 서버 연결
- **Goose** — 데이터 디렉토리 및 시크릿 키 설정
- **OpenCode** — 바이너리 경로 및 config home 설정
- **OpenHands** — 서버 런처 및 홈 디렉토리 설정

## 기능

### 채팅 사이드바
VS Code의 보조 사이드바에서 활성 에이전트와 대화하세요. 명령 팔레트에서 열기: `Junction: Open Sidebar`.

### 워크스페이스 컨텍스트
파일을 채팅 입력에 드래그 앤 드롭하거나, 파일이나 선택 영역을 우클릭하여 현재 스레드에 추가하세요.

### 모델 및 추론 선택기
사이드바 헤더에서 모델을 선택하고 세션별로 추론 노력을 설정하세요.

### Markdown 렌더링
어시스턴트 응답, 도구 호출 카드, 추론 블록, diff가 구문 강조와 함께 인라인으로 렌더링됩니다.

### 채팅 레이아웃
컴팩트 모드(활동을 아코디언으로 접기)와 타임라인 모드(시간순 추론 흐름과 고정 사용자 프롬프트) 간에 전환하세요.

### 후속 모드
에이전트가 완료될 때 메시지를 큐에 추가하거나, 턴 중간에 방향을 전환하거나, 중단하고 리디렉션하세요. 글로벌 또는 브리지별로 구성 가능합니다.

### 자동 재연결
연결이 끊어지면 Junction은 자동으로 런타임에 재연결됩니다. 수동 재시작이 필요 없습니다.

## 테마

Junction에는 두 가지 내장 레이아웃이 있습니다. **컴팩트** 모드는 활동을 요약 아코디언으로 접어 조밀한 뷰를 제공합니다.
**타임라인** 모드는 점 표시기, 추론 펼침, 주황색 강조 테마가 있는 시간순 활동 레일을 표시합니다.
두 레이아웃 모두 VS Code 컬러 테마에 적응합니다.

## 스플래시 화면 및 애니메이션

Junction은 워드마크 뒤에 매트릭스 스타일의 비 효과가 있는 애니메이션 스플래시 화면으로 열립니다.
스플래시 화면은 에디터 내 애니메이션 설정 패널을 통해 완전히 커스터마이즈할 수 있습니다.

### 문자 세트
비 효과는 10가지 문자 세트를 지원합니다: 가타카나, Matrix Latin, 라틴, 히라가나, CJK, 한글, 이모지, 바이너리, 기호, 사용자 정의.
구성 가능한 희귀도로 이모지 드롭을 섞거나, 자신만의 문자 세트를 제공할 수 있습니다.

### 비 컨트롤
- **방향** — 비가 위로 또는 아래로 떨어지도록 전환
- **역방향 확률** — 드롭이 반대 방향으로 갈 확률을 백분율로 설정
- **사이드 바운스** — 비가 화면 밖으로 떨어지지 않고 좌우 가장자리에서 바운스
- **중력, 바운스, 충돌, 속도** — 드롭이 워드마크와 상호작용하는 방식을 조절
- **양, 크기 변화, 색상 변화, 불투명도 범위** — 비의 밀도와 외관을 제어
- **사용자 정의 색상** — 비와 워드마크의 색상과 알파를 선택
- **이모지 혼합** — 켜고 희귀도를 1/N으로 설정 (1 = 모두 이모지, 1000000 = 백만 분의 일)

### 종료 애니메이션
스플래시가 닫힐 때 워드마크는 9가지 애니메이션 모드 중 하나로 종료됩니다.
각 모드에는 드롭다운에서 선택하면 나타나는 전용 컨트롤 슬라이더가 있습니다.

- **Spiral out** — 글자가 중심에서 바깥쪽으로 나선형으로 이동
- **Spiral in** — 글자가 구성 가능한 반지름과 길이로 좁아지는 나선형으로 수렴
- **Explode** — 글자가 중력과 함께 바깥쪽으로 폭발
- **Explode 2** — 가장자리에서 바운스하는 물리 기반 폭발, 힘·카오스·축별 모멘텀 구성 가능
- **Float away** — 글자가 방향 기반 기울기와 함께 위로 떠다님
- **Horizontal flatten** — 글자가 수평으로 퍼지고 1px 선으로 눌림, 유지 시간 구성 가능
- **Explode weak** — 힘이 약한 부드러운 폭발
- **Starwars crawl** — 글자가 구성 가능한 대상 Y 위치의 소실점으로 수렴
- **Explode 3** — 워드마크가 개별 픽셀로 산산조각, 축별 모멘텀 제어
- **Rain push** — 글자가 분리되고 비가 물리적으로 화면 밖으로 밀어냄
- **Random** — 매번 다른 모드를 선택

### 애니메이션 설정 패널
채팅 헤더의 톱니바퀴 아이콘에서 애니메이션 설정을 엽니다. Chat, Bobber, Splash의 세 가지 탭이 있습니다.
Splash 탭에는 두 개의 접을 수 있는 아코디언(Appearance와 Motion), 모드별 슬라이더가 있는 종료 모드 드롭다운, 애니메이션을 테스트하기 위해 클릭할 수 있는 라이브 미리보기 캔버스가 있습니다.
패널은 높이 제한 없이 완전히 드래그 및 리사이즈 가능합니다.

## 설치

### 소스에서
```bash
npm install
./compile-and-install.sh
# 그런 다음: Ctrl+Shift+P → Developer: Reload Window
```

### 요구 사항
- VS Code 1.120.0 이상
- 로컬 에이전트 런타임 실행 중 (예: OpenClaw Gateway, Hermes 대시보드, Souveraine 서버)
