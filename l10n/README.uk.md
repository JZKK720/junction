# Junction

Панель чату для VS Code, яка з'єднує ваш редактор з локальними AI-агентами для програмування.

`7 бекендів` · `Панель чату` · `Контекст робочого простору` · `Анімований екран` · `Ліцензія MIT`

![Дві знайомі теми](../media/two_familiar_skins.png)

Junction — це панель чату для VS Code, яка з'єднується з локальними AI-агентами для програмування, що працюють на вашому комп'ютері.
Вона взаємодіє з кількома бекендами агентів через єдиний інтерфейс — перемикайтеся між ними, не змінюючи свій робочий процес.

## Підтримувані бекенди

Junction підключається до будь-якого з цих локальних середовищ виконання агентів:

- **OpenClaw** — інтеграція з WebSocket-шлюзом та управління сеансами й моделями
- **Hermes** — нативна підтримка WebSocket та REST API для панелі керування
- **Souveraine** — інтеграція з HTTP-сервером та керований запуск середовища виконання
- **MiMoCode** — автоматичний або попередньо налаштований запуск сервера MiMo
- **Goose** — конфігурація каталогу даних та секретного ключа
- **OpenCode** — шлях до виконуваного файлу та налаштування домашнього каталогу конфігурації
- **OpenHands** — запуск сервера та конфігурація домашнього каталогу

## Можливості

### Панель чату
Спілкуйтеся з активним агентом з другої бічної панелі VS Code. Відкрийте через палітру команд: `Junction: Open Sidebar`.

### Контекст робочого простору
Перетягніть файли до поля введення чату або клацніть правою кнопкою миші на файлі чи виділенні, щоб додати його до потоку обговорення.

### Вибір моделі та рівня міркування
Оберіть модель і встановіть зусилля міркування для кожного сеансу з заголовка панелі.

### Рендеринг Markdown
Відповіді агента, картки викликів інструментів, блоки міркувань та diff-и відображаються inline з підсвіткою синтаксису.

### Макети чату
Перемикайтеся між компактним режимом (активність згорнута в акордеони) та режимом часової шкали (хронологічний потік міркувань із закріпленими повідомленнями користувача).

### Режими подальших повідомлень
Ставте повідомлення в чергу на час, поки агент завершує роботу, спрямовуйте в середині ходу або переривайте та перенаправляйте. Налаштовується глобально або для кожного мосту.

### Автоматичне перепідключення
Junction автоматично перепідключається до середовища виконання при розриві з'єднання. Перезапуск вручну не потрібен.

## Теми

Junction містить два вбудованих макети. **Компактний** режим згортає активність у підсумкові акордеони для щільного вигляду.
Режим **часової шкали** показує хронологічну рейку активності з точковими індикаторами, розкриттям міркувань та помаранчевою акцентною темою.
Обидва макети адаптуються до кольорової теми вашого VS Code.

## Екран заставки та анімації

Junction відкривається з анімованим екраном заставки з ефектом матричного дощу позаду логотипу.
Екран заставки повністю налаштовується через панель налаштувань анімації в редакторі.

### Набори символів
Ефект дощу підтримує 10 наборів символів: Катакана, Matrix Latin, Латиниця, Хіраґана, CJK, Хангиль, Емоджі, Двійковий, Символи та Власний.
Додавайте емоджі-краплі з налаштовуваною рідкістю або вкажіть власний набір символів.

### Керування дощем
- **Напрямок** — перемикайте падіння дощу вгору або вниз
- **Шанс зворотного напрямку** — встановіть відсоток крапель, що рухаються у протилежному напрямку
- **Відскок від країв** — дощ відскакує від лівого/правого краю замість падіння за межі екрана
- **Гравітація, відскок, зіткнення, швидкість** — налаштуйте рух крапель та їх взаємодію з логотипом
- **Кількість, варіація розміру, варіація кольору, діапазон прозорості** — керуйте щільністю та виглядом дощу
- **Власний колір** — оберіть колір та альфа-канал для дощу та логотипу
- **Змішування емоджі** — увімкніть та встановіть рідкість як 1/N (1 = все емоджі, 1000000 = один на мільйон)

### Анімації виходу
Коли заставка зникає, логотип виходить через один з 9 режимів анімації.
Кожен режим має власний набір повзунків керування, які з'являються при виборі з випадаючого меню.

- **Спіраль назовні** — літери спірально рухаються від центру
- **Спіраль всередину** — літери сходяться у звужувану спіраль із налаштовуваним радіусом та довжиною
- **Вибух** — літери розлітаються під дією гравітації
- **Вибух 2** — фізичний вибух з відскоком від країв, налаштовувана сила, хаос та момент по осях
- **Відпливання** — літери спливають вгору з нахилом залежно від напрямку
- **Горизонтальне сплющення** — літери розтягуються горизонтально та стискаються у лінію 1px із налаштовуваним часом утримання
- **М'який вибух** — менш потужний вибух з меншою силою
- **Starwars crawl** — літери сходяться до точки зникнення із налаштовуваною Y-позицією цілі
- **Вибух 3** — логотип розбивається на окремі пікселі з керуванням моменту по осях
- **Підштовхування дощем** — літери від'єднуються, і дощ фізично виштовхує їх за межі екрана
- **Випадковий** — щоразу обирає інший режим

### Панель налаштувань анімації
Відкрийте налаштування анімації через іконку шестерні в заголовку чату. Вона має три вкладки — Чат, Бобер та Заставка.
Вкладка Заставка містить два згортаемих акордеони (Зовнішній вигляд та Рух), випадаюче меню режиму виходу з повзунками для кожного режиму та живий прев'ю-канвас, на який можна натиснути для тестування анімацій.
Панель повністю перетягується та змінює розмір без обмеження висоти.

## Встановлення

### З вихідного коду
```bash
npm install
./compile-and-install.sh
# Потім: Ctrl+Shift+P → Developer: Reload Window
```

### Вимоги
- VS Code 1.120.0 або вище
- Локальне середовище виконання агента (напр. OpenClaw Gateway, панель керування Hermes, сервер Souveraine)
