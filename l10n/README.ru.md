# Junction

Боковая панель чата для VS Code, подключающая ваш редактор к локальным ИИ-агентам кодирования.

`7 бэкендов` · `Боковая панель чата` · `Контекст рабочей области` · `Анимированный splash` · `Лицензия MIT`

![Две знакомые темы](../media/two_familiar_skins.png)

Junction — это панель чата для VS Code, которая подключается к локальным ИИ-агентам кодирования, работающим на вашем компьютере.
Она взаимодействует с несколькими бэкендами агентов через единый интерфейс — переключайтесь между ними, не меняя свой рабочий процесс.

## Поддерживаемые Бэкенды

Junction подключается к любому из этих локальных рантаймов агентов:

- **OpenClaw** — Интеграция WebSocket gateway с управлением сессиями и моделями
- **Hermes** — Нативная поддержка WebSocket дашборда и REST API
- **Souveraine** — Интеграция HTTP-сервера с управляемым запуском рантайма
- **MiMoCode** — Автоматически запускаемое или предварительно настроенное подключение к серверу MiMo
- **Goose** — Конфигурация каталога данных и секретного ключа
- **OpenCode** — Настройки пути к бинарному файлу и config home
- **OpenHands** — Лаунчер сервера и конфигурация домашнего каталога

## Возможности

### Боковая Панель Чата
Общайтесь с вашим активным агентом из вторичной боковой панели VS Code. Откройте через Command Palette: `Junction: Open Sidebar`.

### Контекст Рабочей Области
Перетаскивайте файлы в поле ввода чата или нажмите правой кнопкой мыши на файл или выделение, чтобы добавить их в текущий тред.

### Выбор Модели и Рассуждения
Выберите модель и установите уровень рассуждения для сессии из заголовка боковой панели.

### Рендеринг Markdown
Ответы ассистента, карточки вызовов инструментов, блоки рассуждений и diff'ы отображаются инлайн с подсветкой синтаксиса.

### Раскладки Чата
Переключайтесь между компактным режимом (активность свёрнута в аккордеоны) и режимом хронологии (хронологический поток рассуждений с закреплёнными промптами пользователя).

### Режимы Follow-Up
Ставьте сообщения в очередь на момент завершения агента, направляйте в середине хода или прерывайте и перенаправляйте. Настраивается глобально или для каждого моста.

### Автоматическое Переподключение
Junction автоматически переподключается к рантайму при разрыве соединения. Ручной перезапуск не требуется.

## Темы

Junction включает две встроенные раскладки. **Компактный** режим сворачивает активность в аккордеоны-сводки для плотного отображения.
Режим **Хронология** показывает хронологическую панель активности с точечными индикаторами, раскрытием рассуждений и оранжевым акцентным оформлением.
Обе раскладки адаптируются к вашей цветовой теме VS Code.

## Заставка и Анимации

Junction открывается с анимированной заставкой с эффектом дождя в стиле matrix за логотипом.
Заставка полностью настраивается через панель настроек анимации в редакторе.

### Наборы Символов
Эффект дождя поддерживает 10 наборов символов: Катакана, Matrix Latin, Латиница, Хирагана, CJK, Хангыль, Эмодзи, Двоичный, Символы и Пользовательский.
Мешайте капли эмодзи с настраиваемой редкостью или укажите свой набор символов.

### Управление Дождём
- **Направление** — переключите дождь, падающий вверх или вниз
- **Шанс разворота** — установите процент капель, идущих в противоположном направлении
- **Отскок от краёв** — дождь отскакивает от левого/правого края вместо падения за экран
- **Гравитация, отскок, столкновение, скорость** — настройте движение капель и их взаимодействие с логотипом
- **Количество, вариация размера, вариация цвета, диапазон прозрачности** — управляйте плотностью и внешним видом дождя
- **Пользовательский цвет** — выберите цвет и альфа-канал для дождя и логотипа
- **Смешивание эмодзи** — включите и установите редкость как 1/N (1 = все эмодзи, 1000000 = один на миллион)

### Анимации Выхода
При закрытии заставки логотип выходит через один из 9 режимов анимации.
Каждый режим имеет свой набор ползунков управления, которые появляются при выборе из выпадающего списка.

- **Spiral out** — буквы расходятся спиралью от центра
- **Spiral in** — буквы сходятся в сужающуюся спираль с настраиваемым радиусом и длиной
- **Explode** — буквы взрываются наружу с гравитацией
- **Explode 2** — физический взрыв с отскоком от краёв, настраиваемая сила, хаос и импульс по осям
- **Float away** — буквы плывут вверх с наклоном, зависящим от направления
- **Horizontal flatten** — буквы растягиваются по горизонтали и сплющиваются в линию 1px с настраиваемым временем удержания
- **Explode weak** — более мягкий взрыв с меньшей силой
- **Starwars crawl** — буквы сходятся к точке схода с настраиваемой целевой позицией Y
- **Explode 3** — логотип разлетается на отдельные пиксели с управлением импульсом по осям
- **Rain push** — буквы отсоединяются, и дождь физически выталкивает их за экран
- **Random** — выбирает разный режим каждый раз

### Панель Настроек Анимации
Откройте настройки анимации через иконку шестерёнки в заголовке чата. Она содержит три вкладки — Chat, Bobber и Splash.
Вкладка Splash содержит два сворачиваемых аккордеона (Appearance и Motion), выпадающий список режима выхода с ползунками для каждого режима и живой холст предпросмотра, по которому можно кликнуть для тестирования анимаций.
Панель полностью перетаскиваемая и изменяемая по размеру без ограничения высоты.

## Установка

### Из исходного кода
```bash
npm install
./compile-and-install.sh
# Затем: Ctrl+Shift+P → Developer: Reload Window
```

### Требования
- VS Code 1.120.0 или выше
- Запущенный локальный рантайм агента (например, OpenClaw Gateway, дашборд Hermes, сервер Souveraine)
