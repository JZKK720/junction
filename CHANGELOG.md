# Changelog

All notable changes to Junction are documented here.

## [0.0.1] - 2026-06-24

Initial public release.

### Added
- Chat sidebar in VS Code's secondary sidebar for talking to local AI coding agents.
- Multi-bridge support with a unified interface across backends: OpenClaw, Hermes,
  Souveraine, MiMoCode, Goose, OpenCode, and OpenHands.
- Workspace context: drag-and-drop files into the composer, or right-click a file or
  selection to add it to the current thread.
- Per-session model and reasoning-effort picker in the sidebar header.
- Inline Markdown rendering for assistant responses, tool-call cards, reasoning blocks,
  and diffs.
- Two chat layouts: compact (activity folded into accordions) and timeline
  (chronological reasoning flow with sticky user prompts).
- Follow-up modes: queue, steer mid-turn, or interrupt — global or per-bridge.
- Automatic reconnection to the agent runtime when a connection drops.
- Animated splash screen with a customizable matrix-style rain effect and exit
  animations, configurable from an in-editor settings panel.
